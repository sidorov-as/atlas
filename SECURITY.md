# Security Policy

## Supported Versions

Atlas is prerelease software: there is no tagged release yet, and only the `main`
branch is supported. Once the first tagged release (`v0.1.0`) is published, this
section will be updated with a concrete supported-versions table.

| Version | Supported |
|---------|-----------|
| `main`  | ✅         |

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately using
[GitHub Security Advisories](https://github.com/sidorov-as/atlas/security/advisories/new)
rather than opening a public issue or pull request. This lets us investigate and
ship a fix before the details are public.

Include as much detail as you can:

- The affected component or code path.
- Steps to reproduce, or a proof of concept.
- The potential impact as you understand it.

We aim to acknowledge new reports within 5 business days and to keep you updated
as we work on a fix. Once a fix is available, we'll coordinate with you on
disclosure timing and credit, if you'd like it.

For how to propose non-security changes, see [`CONTRIBUTING.md`](CONTRIBUTING.md).
