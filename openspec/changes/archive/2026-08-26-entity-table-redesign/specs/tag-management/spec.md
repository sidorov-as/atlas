## ADDED Requirements

### Requirement: Tag colors section on the Settings page
The Settings page SHALL present the tag color table under its own "Tag colors" section subheading, distinct from the page's top-level title, so that additional, unrelated settings sections can be added to the same page later without implying they are also about tag colors.

#### Scenario: Settings page labels the tag table's section
- **WHEN** an admin opens the Settings page
- **THEN** the tag color table appears under a "Tag colors" section subheading, below the page's generic "Settings" title
